# PageSpeed (mobiili) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise rentunruusu.com from mobile 64 / a11y 91 / agentic 2/3 (PageSpeed 3.10.2026) to ≥ 90 / 100 / 3/3, and fix the same root causes on the five subpages.

**Architecture:** Static site, no build step, served by Vercel from `website/` (`cleanUrls`). The fixes are: self-hosted fonts (kills the 880 ms cross-origin render-blocking chain), WebP variants via `<picture>` with the original JPG/PNG as fallback (generated by a repeatable `cwebp` script), the hero turned from a CSS background into a prioritised `<img>`, below-the-fold images lazy, intrinsic `width`/`height` everywhere, ARIA/contrast/heading fixes, and CSS minified at deploy time only (source stays readable).

**Tech Stack:** HTML/CSS/vanilla JS, `cwebp` (Homebrew `webp`), Node 26 `node:test` (zero deps), Lighthouse 13.5 via `npx`, Vercel.

## Global Constraints

- No runtime dependencies, no `package.json`; `website/` must keep working when uploaded as-is (README promise).
- Originals (`*.jpg`, `*.png`) stay in place — they are `<picture>` fallbacks and schema/og images.
- Never `git add -A`: the repo root has untracked owner photos (`außen/neu*.jpeg`, `cafe neu/`, `saal neu/`). Add exact paths.
- Every commit auto-pushes and Vercel deploys `main` → every task must leave the site fully working.
- Brand palette is fixed (`brand-guidelines.md`); the only new colour is a darker brass for text, `#825C33`, documented in §3.4.
- Baseline (local Lighthouse 13.5, mobile, live site): index 66/91, galleria 78/95, tapahtumat 59/96 (LCP 37.2 s), meista 90/96, yhteystiedot 89/95, juhlatila-hameenlinna 90/96. Measurements in the session scratchpad.
- Not fixable here: Google Maps `cache-insight` on yhteystiedot/juhlatila (third party).

```bash
#!/usr/bin/env bash
# Rentun Ruusu — WebP-versiot sivuston kuvista. Vaatii cwebp:n (brew install webp).
# Aja repon juuresta: tools/optimoi-kuvat.sh
#
# Alkuperäiset JPG/PNG-tiedostot jäävät paikalleen: ne ovat <picture>-elementtien
# varakuvia ja schema/og-kuvia. Kun vaihdat kuvan, aja skripti uudelleen — HTML
# viittaa versioihin nimellä <nimi>-<leveys>.webp.
set -euo pipefail
cd "$(dirname "$0")/../website/assets/img"

webp() { # lähde kohde leveys [cwebp-optiot...]
  local src=$1 out=$2 w=$3; shift 3
  cwebp -quiet -mt -m 6 -sharp_yuv "$@" -resize "$w" 0 "$src" -o "$out"
}
kuva() { # lähde leveys... → <nimi>-<leveys>.webp
  local src=$1; shift
  for w in "$@"; do webp "$src" "${src%.*}-$w.webp" "$w" -q 72; done
}

# Etusivun hero: vaakaversiot + puhelimille pystyrajaus kuvan keskeltä (900×1200)
kuva hero-sali.jpg 960 1600
for w in 600 900; do webp hero-sali.jpg "hero-sali-p-$w.webp" "$w" -q 72 -crop 350 0 900 1200; done

# Kuvapinot ja tilakortit
kuva koti-kahvila.jpg 480 800
kuva koti-talo.jpg 480 800
kuva koti-aula.jpg 480 800 1200
kuva gallery/sali-01.jpg 480 800 1200
kuva gallery/kahvila-01.jpg 480 800 1200

# Logo (läpinäkyvä) ja alatunnisteen talo
for w in 280 420; do webp logo.png "logo-$w.webp" "$w" -q 90 -alpha_q 100; done
for w in 720 1280; do webp banner-talo.png "banner-talo-$w.webp" "$w" -q 80; done

# Tapahtumajulisteet
for p in events/sillalailla-poster.png events/luntatupaan-poster.jpg; do
  for w in 480 800; do webp "$p" "${p%.*}-$w.webp" "$w" -q 78; done
done

# Gallerian pikkukuvat samassa koossa (640 px)
for f in gallery/*_t.jpg; do
  cwebp -quiet -mt -m 6 -sharp_yuv -q 72 "$f" -o "${f%.jpg}.webp"
done
```
